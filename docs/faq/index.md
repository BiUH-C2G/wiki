# 常见问题汇总

## 生活

1. 插孔位置有限，还可能被桌子遮挡。建议购买插板横着黏在桌上，胶布类型选海绵双面胶，横着贴两行在插板背面即可轻松固定。
2. 可以购买挡水条否则浴室积水会溢出，以及淋浴过高可以考虑买调节器之类的。长度建议买大一点，可以裁切。高度 20cm 左右。
3. 因为浴室和厕所是独立的，所以厕所清洁比较麻烦。但可以买一次性自带药水的马桶刷，或使用酒精湿巾擦拭周围。
4. 扫把的话建议女生用魔术扫把，不然头发缠得到处都是。
5. 晾衣杆是不可活动的类型，需购买晾衣叉。楼下美宜佳可以购买，但数量有限。若到校时间较晚可以网购，地址填写学校。
6. 上下铺之间的梯子角度较陡，容易打滑，可以购买防滑条。
7. 建议提前购置足量活性炭。
